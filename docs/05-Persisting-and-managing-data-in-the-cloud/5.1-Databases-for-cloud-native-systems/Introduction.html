5.1 云原生系统的数据库

云原生应用程序通常需要存储和管理数据。在传统的应用程序开发中，存储通常由运维工程师和数据库管理员处理。但云和 DevOps 实践使开发人员能够选择最适合应用程序需求的数据服务，并使用与云原生应用程序相同的方式进行部署。

本节将介绍云环境中的数据服务，包括主要类别和挑战。
